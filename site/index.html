04 · how it ships

How this site is deployed

This page is a small, working example of the kind of pipeline I want to build professionally. Every change goes through the same five steps.

  1. 01

    Push

    A commit lands on main in GitHub.

  2. 02

    Validate

    GitHub Actions validates the HTML, checks for leftover placeholders, and runs terraform validate.

  3. 03

    Authenticate

    The workflow assumes a least-privilege IAM role through OIDC. No stored AWS keys.

  4. 04

    Deploy

    aws s3 sync uploads changed files to a private, versioned S3 bucket.

  5. 05

    Serve

    The CloudFront cache is invalidated and the new version is live over HTTPS.

Infrastructure: S3, CloudFront, IAM, ACM, and Route 53, all defined in Terraform. Read the code
